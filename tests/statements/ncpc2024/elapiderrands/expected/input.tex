
The first line contains one integer $N$ ($1 \leq N \leq 20$), the number of points you must visit.

The following $N$ lines each contain two integers $x_i, y_i$ ($0 \leq x_i, y_i \leq 10^4$).

Apart from the sample, there will be $100$ testcases, all with $N = 20$. The 
(manhattan) distance between any two of the points (including the starting 
point $(0,0)$) will be at least $20$. Within these constraints, the points 
$(x_i, y_i)$ were generated uniformly at random.

Note that the sample does not satisfy the distance requirement. Your solution \textbf{does not} need to solve the sample to get accepted.

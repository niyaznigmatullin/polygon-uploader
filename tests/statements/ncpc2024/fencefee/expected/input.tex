

The first line contains an integer $F$ ($3 \leq F \leq 1000$), the number of fence line segments.
The next $F$ lines contain four integers each, $x_1$, $y_1$, $x_2$,
$y_2$ ($0 \leq x_1, y_1, x_2, y_2 \leq 1000$), representing a straight-line fence section.

No two fence line segments intersect. Since fencing is both expensive and tedious, you may assume that every
fence line segment is necessary and serves to bound fields.
All fences farmers have are connected.

In other words, the graph that consists of endpoints and fences is planar, connected, and has no bridges.

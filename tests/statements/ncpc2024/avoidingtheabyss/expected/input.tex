
The first line contains two integers $x_s$ and $y_s$ ($-10^4 \leq x_s, y_s \leq 10^4$).

The second line contains two integers $x_t$ and $y_t$ ($-10^4 \leq x_t, y_t \leq 10^4$).

The third line contains two integers $x_p$ and $y_p$ ($-10^4 \leq x_p, y_p \leq 10^4$).

The problem is not adaptive, i.e. for every test case there exist four integers 
$x_l, y_l, x_r, y_r$ ($-10^4 \leq x_l < x_r \leq 10^4$, $-10^4 \leq y_l < y_r \leq 10^4$) 
that constitute a swimming pool. 
The start and end points are always strictly outside the swimming pool, and the point $(x_p,y_p)$
is inside (or on the border). The start and end points are always distinct.

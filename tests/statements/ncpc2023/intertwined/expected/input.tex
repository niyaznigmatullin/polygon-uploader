

The first line contains an integer $n$, the number of pillars, and an integer $d$, the length of the rope 
($1 \leq n \leq 10^5$, $1 \leq d \leq 10^9$).

The following $n$ lines each contain two integers $x_i$, $y_i$, the coordinates of the
$i$th pillar ($-10^9 \leq x_i, y_i \leq 10^9$) for $i \in 1, 2, \ldots, n$. None of these pillars will lie on the rope.


    The input consists of:
    \begin{itemize}
        \item One line containing an \emph{even} integer $n$ ($4 \leq n\leq 10^5$), the number of points needed to describe the cake's shape.
        \item $n$ lines, each containing two integers $x$, $y$ ($0\leq x,y \leq 10^6$), the $x$ and $y$ coordinates of a point on the border of the cake's shape.
    \end{itemize}
    The following additional guarantees are given for the shape of the cake:
    \begin{itemize}
    	\item The cake has a $180^\circ$ rotational symmetry.
    	\item The points are given in counterclockwise order.
    	\item No three consecutive points are collinear.
    	\item The shape is simple (no segments intersect and only consecutive segments touch at their ends).
    \end{itemize}

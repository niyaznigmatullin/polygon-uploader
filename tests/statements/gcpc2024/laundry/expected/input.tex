
    The input starts with a line containing one integer $t$ ($1 \leq t \leq 10^4$), the number of test cases.
    Then for each test case: 
    \begin{itemize}
        \item One line with an integer $k$ ($1\leq k\leq 10^9$), the number of items you can put in one load.
        \item One line with seven integers $c_1, \ldots, c_7$ ($0 \leq c_i \leq 10^9$), the number of items for each combination of programmes. 
        The integers are given in this order: A, B, C, AB, BC, AC, ABC. 
        For example, $c_4$ must be washed using either programme A or programme B.  
    \end{itemize}

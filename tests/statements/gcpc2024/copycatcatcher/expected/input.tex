
    The input consists of:
    \begin{itemize}
        \item A description of the reference, consisting of:
            \begin{itemize}
                \item One line containing an integer $n$ ($1\leq n \leq 2\,000$), the number of tokens in the reference.
                \item One line containing $n$ tokens, each consisting only of the characters `\texttt{a}'-`\texttt{z}', `\texttt{A}'-`\texttt{Z}', `\texttt{0}'-`\texttt{9}', `\texttt{(}' and `\texttt{)}'.
            \end{itemize}
        \item An integer $q$ ($1 \leq q \leq 2\,000$), the number of queries.
        \item $2\cdot q$ lines, each two lines in the same format as the reference.
    \end{itemize}
    It is guaranteed that each query as well as the reference consist of at most $2\,000$ characters (excluding spaces).
    Tokens are separated by single spaces.

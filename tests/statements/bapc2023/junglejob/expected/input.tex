
    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($1\leq n\leq 1000$), the number of
    branches in the tree.
        \item $n-1$ lines, the $i$th of which ($1\leq i\leq n-1$) contains an integer $p_i$ ($0\leq p_i<i$),
            indicating that branch $i$ is connected to the upper end of branch $p_i$.
    \end{itemize}
    The branches are numbered from $0$ to $n-1$, inclusive. Branch $0$ is
    connected to the roots of the tree and can also host a single monkey.


    The input consists of:
    \begin{itemize}
        \item One line with three integers $n$, $m$, and $k$ ($1\leq n\leq 10^5$, $0\leq m\leq n$, $1\leq k\leq 10$),
            the number of packages being upgraded,
            the number of packages that finished downloading, and
            the number of packages that can be downloaded in parallel.
        \item One line with $n$ integers $s$ ($1\leq s\leq 10^9$), the sizes of the packages being upgraded.
    \end{itemize}

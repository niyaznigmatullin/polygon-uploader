
    The input consists of:
    \begin{itemize}
        \item One line with two integers $n$ and $m$ ($1\leq n\leq 1000$, $1 \leq m \leq 1000$),
            the number of cities and the number of letters in each city name.
        \item $n$ lines, each with a string of length $m$, the name of a city.
    \end{itemize}
    The city names only consist of lowercase English letters (\texttt{a-z}).

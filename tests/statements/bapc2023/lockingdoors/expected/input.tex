
    The input consists of:
    \begin{itemize}
        \item One line with two integers $n$ and $m$ ($2\leq n \leq 10^5$, $1\leq m \leq 10^6$), the number of rooms and doors, respectively.
        \item Then follow $m$ lines, each containing two distinct integers $a$ and $b$ ($1 \leq a,b \leq n$, $a \neq b$),
            indicating a door connecting rooms $a$ and $b$ which can only be locked from room
            $a$.
    \end{itemize}
    You may assume that all ordered pairs $(a,b)$ are distinct and that you can
    walk from any room in the mall to any other room if all the doors are open.


    The input consists of:
    \begin{itemize}
        \item One line with two integers $h$ and $w$ ($1 \leq h \leq 4000$, $1 \leq w \leq 50$),
            the height and width of the chosen pattern.
        \item $h$ lines, each with a string of $w$ characters $c$ ($c \in \{\texttt{w}, \texttt{r}, \texttt{g}, \texttt{b}\}$),
            describing the pattern.
    \end{itemize}

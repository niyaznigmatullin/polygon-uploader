
    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($2\leq n\leq 50\,000$), the number of possible messages.
        \item $n$ lines (one for each message),
            each with an integer $k$ ($2\leq k\leq 10^5$), the number of integers assigned to the message,
            followed by those $k$ integers $x$ ($1\leq x\leq 10^9$).
            It is guaranteed that the $k$ integers in a message are pairwise distinct.
    \end{itemize}
    The total number of integers in all messages combined is at most $10^5$.


    The input consists of:
    \begin{itemize}
        \item One line with two integers~$n$ and $m$
            ($2\leq n\leq 10^{5}$,
            $1\leq m\leq 2\cdot 10^{5}$),
            the number of sites and the number of roads.
        \item $m$ lines, each with two integers~$u$ and $v$ ($1\leq u < v \leq n$),
            indicating there is a road between sites $u$ and $v$.
            Roads can be travelled in either direction.
            Each pair of sites is connected by at most one road.
    \end{itemize}

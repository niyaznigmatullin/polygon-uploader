
    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($1\leq n\leq 35$), the number of floors to visit.
        \item One line with $n$ integers $f_1,\ldots,f_n$ ($0\leq f_i\leq10^6$ for each $i$), the numbers of the floors you must visit.
        \item One line with $n$ integers $t_1,\ldots,t_n$ ($1\leq t_i\leq10^9$ for each $i$), the necessary time spent on each floor in seconds.
    \end{itemize}
    No two consecutive floors $f_i,f_{i+1}$ are equal, and $f_1$ is non-zero.

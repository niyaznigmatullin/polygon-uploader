
    The input consists of:
    \begin{itemize}
        \item One line with a string $s$, the given text to check.
        \item One line with an integer $n$, the number of words in the word list.
        \item $n$ lines, each with a string $w$ ($6 \leq |w| \leq 10$), the words in the word list.
            The words in the word list are distinct and fixed per test case.
    \end{itemize}
    All input strings only consist of English lowercase letters (\texttt{a-z}).

    Your submission will be run on exactly $100$ test cases, all of which will have $|s| = 3\cdot10^5$ and $n = 5000$.
    The samples are smaller and for illustration only.

    For each test case where $s$ is human-made, $s$ is fixed and does not change between each of your submissions.
    For each test case where $s$ is generated by an LLM,
    each of your submissions will receive a new string $s$,
    generated from independently and uniformly picking random English lowercase letters (\texttt{a-z}).


    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($4 \leq n \leq 10^5$), the number of points of the wheel.
        \item $n$ lines, each with two integers $x$ and $y$ ($\left| x \right|, \left| y \right| \leq 10^5$), the coordinates of the points.
    \end{itemize}

    The points are given in counterclockwise order and form a convex polygon with no internal angle below $90$ degrees.
    Note that the convex polygon may contain \textbf{collinear} points, but no two points are at the same position.

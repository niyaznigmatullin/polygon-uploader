
  Output an integer $m$ ($m\leq n$), the number of points of the bike path,
  followed by $m$ lines containing the coordinates of the bike path in counterclockwise order.
  Note that two consecutive points must have either the same x-coordinate or the same y-coordinate, and that no three consecutive points may be collinear.

  If there are multiple valid solutions, you may output any one of them.

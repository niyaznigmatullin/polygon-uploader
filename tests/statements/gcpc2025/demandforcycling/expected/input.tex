
  The input consists of:
  \begin{itemize}
    \item One line with an integer $n$ ($4 \leq n \leq 10^5$), the number of points of the outline of the city.
    \item $n$ lines, each with two integers $x$ and $y$ ($1 \leq x,y \leq 10^9$), the coordinates of the points.
  \end{itemize}
  Additionally, the following is guaranteed:
  \begin{itemize}
    \item The points of the city's outline are given in counterclockwise order.
    \item Two consecutive points have either the same x-coordinate or the same y-coordinate.
    \item No three consecutive points are collinear.
    \item The outline of the city does not intersect itself.
  \end{itemize}

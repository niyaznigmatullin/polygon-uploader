
The input consists of:
\begin{itemize}
\item One line with five integers $h$, $w$, $k$, $i$, and $t$ ($3 \le h,w \le 100$, $k,i,t \ge 1$, $k+i+t = h\cdot w$), where $h$ and $w$ are the height and width the word search grid should have, and $k$, $i$, and $t$ specify the required number of occurrences of `\texttt{K}', `\texttt{I}' and `\texttt{T}', respectively.
\end{itemize}

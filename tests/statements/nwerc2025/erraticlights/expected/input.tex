
    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($1 \leq n \leq 100$),
            the number of bulbs on the string of lights.
        \item One line with $n$ characters, each character being either `\texttt r', `\texttt g', or `\texttt b',
            indicating the colours of the light bulbs at the start.
    \end{itemize}

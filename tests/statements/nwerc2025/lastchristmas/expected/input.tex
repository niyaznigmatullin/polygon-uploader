
    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($1\leq n \leq 100$), the number of top-10 lists.
        \item $n$ lines, each with $10$ strings $s$ ($1 \leq |s| \leq 20$),
    the first names of the artists of the top-10 list from $1$ to $10$. Each
    name only consists of English lowercase letters (\texttt{a-z}).\footnote{If Madonna does not need a last name, why would other artists need one?}
    \end{itemize}

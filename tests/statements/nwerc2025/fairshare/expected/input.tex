
    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($2 \leq n \leq 10^5$), the size of your dinner group.
        \item $n$ lines, the $i$th of which contains two integers $a_i$ and $b_i$ ($1 \leq a_i, b_i \leq 1000$), the amount of cash person $i$ would contribute if someone else pays and their share of the bill, respectively.
    \end{itemize}

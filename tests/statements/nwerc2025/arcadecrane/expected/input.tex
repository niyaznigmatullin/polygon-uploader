
    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($5 \leq n \leq 1000$), the number of plushies.
        \item One line with $n$ distinct integers $a_1, \ldots, a_n$ ($1 \le a_i \le n$ for each $i$), where $a_i$ is the cuteness value of the $i$th plushie.
    \end{itemize}


    The input consists of:
    \begin{itemize}
        \item One line with three integers $r$, $c$, and $q$
            ($1 \leq r,c \leq 9 \cdot 10^6$, $r \cdot c \leq 9 \cdot 10^6$, $1 \leq q \leq 10^5$),
            the number of rows and columns of the grid,
            and the number of questions.
        \item $r$ lines with $c$ characters, each character being either `\texttt{.}' if the corresponding square indicates land suitable for courses or `\texttt{\#}' otherwise.
        \item $q$ lines, each with two integers $h$ and $w$ ($1 \leq h \leq r$, $1 \leq w \leq c$),
            indicating a question from Harold about the number of Hurdle Hopping courses with
            height $h$ (number of rows in the grid) and width $w$ (number of columns in the grid).
    \end{itemize}

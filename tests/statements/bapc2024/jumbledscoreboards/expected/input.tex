
    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($1\leq n\leq 100$), the number of pictures you received.
        \item $n$ lines, each with two integers $a$ and $b$ ($0 \leq a,b \leq 100$),
            the scores of the two teams in one of the pictures.
    \end{itemize}
    Every pair of scores $(a, b)$ in the input is unique.

    The order of the scores in the input is the order in which you received the pictures.

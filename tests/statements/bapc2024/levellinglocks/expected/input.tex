
    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($2 \le n \le 2\cdot 10^5$), the number of chambers.
        \item One line with $n$ integers $a$ ($1 \le a \le 10^8$), the water level in each chamber.
    \end{itemize}
    The space occupied by the gates is negligibly small.

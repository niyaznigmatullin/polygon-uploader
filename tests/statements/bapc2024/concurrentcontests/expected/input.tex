
    The input consists of:
    \begin{itemize}
        \item One line with two integers $n$ and $m$ ($1\leq n\leq 2\cdot10^5$, $1 \leq m \leq 100$),
              the number of contestants and the number of contests.
        \item One line with $n$ integers $s$ ($1\leq s\leq10^9$),
              the skill levels of the contestants.
        \item One line with $m$ integers $p$ ($1 \leq p \leq 10^9$),
              the prizes for the winners of the contests.
    \end{itemize}
    The sum of all skill levels is at most $10^9$.

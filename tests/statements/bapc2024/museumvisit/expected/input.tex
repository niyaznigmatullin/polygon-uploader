
    The input consists of:
    \begin{itemize}
        \item One line with two integers $n$ and $m$ ($1\leq n,m\leq 2\cdot10^5$),
            the number of days in the foreseeable future and the number of exhibitions planned in those days.
        \item One line with $n$ integers $c$ ($1\leq c\leq 10^9$),
            describing for each day the discomfort you will receive when you visit the museum.
        \item $m$ lines, each with two integers $s$ and $e$ ($1\leq s\leq e\leq n$),
            describing the start and end day of an exhibition.
            The start and end days are inclusive: the exhibition can be visited on day $s$, day $e$, and any day in between.
    \end{itemize}

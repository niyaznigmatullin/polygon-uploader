
The first line of input contains an integer $N$ $(1 \leq N \leq 3 \cdot 10^{5})$, the number of jellies initially on your lab bench.

The next $N$ lines describe these jellies, in order. The $i\textsuperscript{th}$ line contains two space-separated integers $h_i$ and $w_i$ $(1 \leq h_i, w_i \leq 10^{6})$, the height and width of the $i\textsuperscript{th}$ jelly.

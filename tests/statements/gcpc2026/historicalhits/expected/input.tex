
    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($1 \le n \le 3000$), the number of cards.
        \item $n$ lines, the $i$th of which contains two integers $a_i, b_i$ ($1 \le a_i, b_i \le 10^9$), the correct year and Harper's guessed year for the song of the $i$th card.
    \end{itemize}
    It is guaranteed that $a_i \ne a_j$ and $a_i \ne b_j$ for all $i \ne j$.

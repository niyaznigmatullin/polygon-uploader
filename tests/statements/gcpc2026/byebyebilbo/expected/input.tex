
    The input consists of:
    \begin{itemize}
        \item One line with two integers $n$ and $k$ ($2 \leq n \leq 10^5$, $1 \le k \le n$), the number of hobbit holes and the firework range.
        \item One line with $n-1$ integers $p_2, p_3, \ldots, p_n$ ($1 \le p_i \leq i-1$), where $p_i$ is the next hole reached when going from hole $i$ toward the town.
    \end{itemize}


    The input consists of:
    \begin{itemize}
        \item $7$ lines with $24$ characters, each character being
            either `\texttt{.}' or `\texttt{x}', with `\texttt{.}' indicating the time
            slots you are available.
        \item One line with two integers $d$ and $h$ ($1 \leq d \leq 7$, $1 \leq h \leq 24$),
            the minimum number of days and hours you have to fill in.
    \end{itemize}

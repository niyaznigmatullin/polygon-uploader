

Swimming for exercise involves assigning swimmers to lanes suited to their
fitness level.

We know the velocity of each swimmer in metres per hour. The swimmers
start in any order but inevitably they will eventually become stuck
behind the slowest swimmer in the lane and start matching their pace.

\begin{figure}[!h]
\centering
\includegraphics[height=0.33\textwidth]{sample3.pdf}
\caption{Illustration of Sample Input 3.}
\end{figure}

If we can assign swimmers to $l$ lanes, how can we ensure that the average
speed of all of the swimmers in the pool (measured in metres per hour)
is as high as possible? Output this average speed and an assignment of
swimmers to lanes.



An image set to be painted onto a tartan canvas consists of $n$ rows of $m$ pixels
with each colour represented as a lowercase letter of the alphabet.

You are going to paint the image using long brush strokes that cover either a
whole row of $m$ pixels, or a whole column of $n$ pixels. Each brush stroke
overwrites any pixels that were previously there. You must cover the whole canvas
with brush strokes.

Is it possible to do so? If so, output a sequence of instructions of the form
\texttt{x=[1-m] [a-z]} or \texttt{y=[1-n] [a-z]}.
If there are multiple sequences, output any of the shortest possible lists of instructions.

\problemname{Inverse Sum}

Given an integer $n>1$, and the equation: $$ \frac{1}{n}=\frac{1}{a}+
\frac{1}{b}$$ Find two distinct positive integers $a,b$ which both satisfy the
above equation, and have a minimal sum $a+b$.


\section*{Input}

\begin{itemize}
  \item The only line of input consists of one integer $n$ ($1 < n \le
      10^8$)~--- the number for the left hand side of the equation.
\end{itemize}

\section*{Output}

Output the best choices for $a$ and $b$ in ascending order.

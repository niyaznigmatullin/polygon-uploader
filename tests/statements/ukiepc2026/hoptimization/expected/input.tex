

\begin{itemize}
  \item One line of input containing the number of cells, $k$ ($1 \le 16$), and the number of hops, $n$ ($1 \le n \le 10^6$).
  \item A second line of input containing $n$ lower-case strings, the $i$\:th string $s_i$ containing
        the target cell for the $i$\:th hop. ($1 \le |s| \le 10$).
\end{itemize}

It is guaranteed that no more than $k$ distinct cell names are given.

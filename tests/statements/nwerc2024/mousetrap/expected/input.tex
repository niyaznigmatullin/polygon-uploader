
\vspace{-1mm}
  The input consists of:
  \begin{itemize}
    \item One line with an integer $n$ ($3 \leq n \leq 2\cdot 10^5$), the number of mice.
    \item $n$ lines, each with two integers $x$ and $y$ ($|x|, |y| \leq 10^7$), the coordinates of a mouse.
  \end{itemize}
  The coordinates of the mice are given in counterclockwise order and form a strictly convex polygon with non-zero area.
  A strictly convex polygon is a convex polygon such that no three consecutive vertices are on a straight line.

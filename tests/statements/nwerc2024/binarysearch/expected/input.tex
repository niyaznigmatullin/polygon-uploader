
The input consists of:
\begin{itemize}
	\item One line with two integers $n$ and $m$ ($1 \leq n \leq 3 \cdot 10^5$, $0 \leq m \leq 3 \cdot 10^5$), the number of vertices and the number of edges.
	\item One line with $n$ integers $a_1,\dots, a_n$ ($a_v \in \{0, 1\}$ for each $v$), where $a_v$ is the number written on vertex $v$.
	\item $m$ lines, each with two integers $u$ and $v$ ($1 \leq u,v \leq n$,
	$u \neq v$), denoting that the vertices $u$ and $v$ are connected by an
	edge. It is guaranteed that every pair of vertices is connected by at most
	one edge.
\end{itemize}

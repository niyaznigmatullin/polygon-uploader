
	The input consists of:
	\begin{itemize}
		\item One line with one integer $n$ $(1\leq n\leq500)$, the number of cranes.
		\item $n$ lines, each with three integers $x$, $y$, and $h$ ($0\leq x,y\leq 10\,000$, $1\leq h\leq 10\,000$), describing the position of the crane and its height in metres.
	\end{itemize}
	It is guaranteed that no two cranes are at the same position and that all heights are distinct.

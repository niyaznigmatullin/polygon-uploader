
The input consists of:
\begin{itemize}
	\item One line with four integers  $n$, $m$, $x$, and $y$ ($1 \leq n, m \leq
	10^5$, $1 \leq y < x \leq 1000$), the number of shelves, the number of books,
	the number of books that fit on a full shelf,
	and the number of books that fit on a shelf next to an art piece.
	\item One line with $n$ integers $a$ ($1 \leq a \leq 10^9$), the heights of the shelves.
	\item One line with $m$ integers $b$ ($1 \leq b \leq 10^9$), the heights of the books.
\end{itemize}


    The input consists of:
    \begin{itemize}
        \item One line with an integer $n$ ($1\leq n\leq 1000$), the number of surnames.
        \item $n$ lines, each with a string $s$ ($1\leq |s|\leq50$), one of the surnames. \\
            The surnames consist of English letters, spaces, and apostrophes
            (\texttt{A-Z}, \texttt{a-z}, `\texttt{ }', `\verb|'|').
    \end{itemize}
    It is guaranteed that the part starting with the first capital letter is unique.
    Names have no leading, trailing, or consecutive spaces.

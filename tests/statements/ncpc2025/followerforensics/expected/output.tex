

If a reconstruction is possible, output a network
\begin{itemize}
\item One line with two integers: the number~$n$ of accounts, and the number~$m$ of connections. This is the same $n$ as in the input.
\item Then $m$ lines, each consisting of two integers $a$ and $b$, specifying that account~$a$ follows account~$b$.
\end{itemize}

Otherwise output ``\texttt{impossible}''.

Note that it is not allowed for an account to follow the same account twice, nor to follow itself.



The input consists of

\begin{itemize}
  \item One line with two integers $N$ and $M$ ($1 \le N \le 200\,000$, $0 \le M \le 1\,000\,000$), the number of vertices and the number of directed edges.
  \item $M$ lines with two distinct integers $u$ and $v$ ($1 \le u,v \le N$), indicating a directed edge from $u$ to $v$.
    There are no duplicate edges.
\end{itemize}
